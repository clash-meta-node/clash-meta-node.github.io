3.2 第二步：获取并导入服务器配置信息

安装好客户端后，你还需要一个“节点”才能连接。节点通常由你的服务提供商提供（可以是自建的VPS，也可以是购买的机场服务）。节点信息通常包含以下参数： - 服务器地址：一个IP地址或域名。 - 端口：一个数字，如1080、443等。 - 密码：一串字符。 - 加密方式：如aes-256-gcm、chacha20-ietf-poly1305等。

导入方式： 1. 手动输入：打开Shadowsocks客户端，点击右下角的“+”号，选择“手动设置”，依次填入上述四个参数。这是最基础的方式。 2. 扫描二维码：如果你的服务商提供了二维码，可以直接在客户端点击“扫描二维码”进行快速导入。 3. 从剪贴板导入：复制服务商提供的SS链接（通常以“ss://”开头），然后在客户端选择“从剪贴板导入”。

3.3 第三步：核心配置与连接测试

导入节点后，你需要进行一些关键设置： 1. 路由模式：这是决定哪些流量走代理的关键。推荐选择“绕过局域网和大陆地址”。这样，访问国内网站时会直连，不影响速度；访问被墙的海外网站时才会走代理，既高效又节省流量。 2. 开启代理：在客户端主界面，点击底部的“连接”按钮或开关，当状态变为“已连接”时，代表代理成功开启。 3. 连接测试：打开手机浏览器，尝试访问一个被封锁的网站（如Google、YouTube）。如果能正常打开，说明配置成功。你也可以在客户端内点击“测试连接”或“延迟测试”来查看当前节点的网络状况。

高级设置（可选）： - 分应用代理：在客户端的“设置”或“应用管理”中，你可以指定哪些APP走代理，哪些APP直连。例如，让浏览器和Twitter走代理，而微信、支付宝等国内应用直连，避免影响本地服务的使用。 - DNS设置：为了防止DNS劫持，建议将客户端的DNS设置为公共DNS，如8.8.8.8（Google）或1.1.1.1（Cloudflare）。

3.4 常见问题与解决方案

问题一：连接失败，提示“无法连接到服务器” - 原因：服务器地址或端口错误；服务器宕机；网络环境限制（如校园网、公司网络封杀了VPN端口）。 - 解决：仔细核对服务器信息；尝试更换其他节点；在客户端中更换连接协议（如将TCP改为KCP或WebSocket）。

问题二：可以连接，但访问速度很慢 - 原因：当前节点负载过高；你的网络到服务器的延迟较大；加密方式选择不当。 - 解决：更换一个延迟更低、负载更小的节点；在客户端中尝试更换加密方式（如从aes-256-gcm改为chacha20-ietf-poly1305，后者速度通常更快）；检查自己手机的网络连接是否正常。

问题三：部分应用无法正常使用（如微信、支付宝） - 原因：开启了全局代理，导致国内应用的流量也被转发到海外服务器，造成访问异常。 - 解决：将路由模式设置为“绕过局域网和大陆地址”；或在“分应用代理”中，将微信、支付宝等国内应用设置为“直连”。

问题四：手机发热、耗电快 - 原因：客户端在后台持续运行，且加密解密过程消耗CPU资源。 - 解决：在不使用科学上网时，记得断开客户端连接；选择资源占用更低的客户端（如Shadowsocks）；在手机设置中限制客户端的后台活动权限（但要注意可能影响连接稳定性）。

FAQ

如何防止 Clash 被系统防火墙阻断？
请在防火墙设置中允许 Clash 的执行文件通过网络访问，并开放其监听端口。若使用 Windows Defender，可在防火墙高级规则中手动添加入站和出站规则，确保代理通信正常。
Surfboard 能否同步 iCloud 配置？
可以。Surfboard 支持 iCloud 同步功能，用户可在不同苹果设备上共享同一配置文件。这样即使更换手机或重装系统，也能自动恢复节点与分流设置。
如何使用 Docker 部署 sing-box 或 v2ray？
选择官方或社区维护的 Docker 镜像，编写 docker-compose.yml 指定配置文件挂载、网络模式与端口映射。使用容器管理可以隔离运行环境、便于日志采集并与反向代理（如 Nginx）协同工作。
Netch 是否支持系统代理？
Netch 不直接修改系统代理，而是通过虚拟网卡（TAP 驱动）实现透明代理。这种方式不会影响浏览器设置，适合游戏和应用程序需要 UDP 支持的场景。
Clash 支持哪些协议？
Clash 支持多种主流代理协议，包括 VMess、VLess、Trojan、Shadowsocks、Snell、Socks5 等。通过配置文件或订阅源，用户可以灵活组合不同协议的节点，实现复杂的分流策略与优先级控制。
SSR 是否还值得使用？
虽然 SSR 的开发早已停止，但由于它配置简单且部分节点仍然兼容，仍有一定使用场景。不过建议用户逐步迁移到更安全的新协议如 VLESS 或 Trojan，以获得更佳性能与隐蔽性。
SSR 节点和 V2Ray 节点可以混合使用吗？
可以，但要使用支持多协议的客户端，如 Clash、Sing-box、Mihomo 等。这类客户端能在同一配置文件中加载不同协议的节点，通过规则分流让 SSR 与 V2Ray 同时工作。
如何把 Clash 规则与本地 hosts 文件结合使用？
可在 Clash 的 rules 中优先设置域名直连规则，并在系统 hosts 中添加常用站点的固定解析以加速 DNS 解析。注意 hosts 优先级高于 DNS，因此修改 hosts 需谨慎以避免与真实解析冲突。
Shadowrocket 节点测速结合策略组的作用？
Shadowrocket 定期测速节点延迟和丢包率，并结合策略组自动选择最佳节点。保证网页、视频和游戏流量走低延迟节点，提高访问速度和连接稳定性。
Mihomo 节点分组如何保证低延迟访问？
将节点按延迟、地区或用途分组，并启用策略组，系统会根据节点健康和延迟自动选择最佳节点。保证网页浏览、视频播放和游戏流量的低延迟稳定连接。
